Data Interpretation is not “more maths” — it is **reading speed + pattern recognition**. In 2025 prelims, five table/chart types cover most of what we see in student mocks and PYQs.

## 1. Missing-value table (profit & loss)

A table gives **CP, SP, profit %** for 4–5 shops with **one blank per row**. You are not asked to find every cell — only the question’s row.

**Tactic:** Convert everything to a **multiplier on CP**:

<Math math="\text{SP} = \text{CP} \times (1 + p/100)" display />

If profit % and SP are known, CP = SP ÷ (1 + p/100). Use **componendo** only if the numbers are ugly; otherwise plug from answer options.

## 2. Dual pie + single ratio question

Two pies (e.g. income split, expense split) with **one** question: “What % of income is rent?”

**Tactic:** Multiply shares:

<Math math="\text{rent share} = \frac{\text{rent}}{\text{expenses}} \times \frac{\text{expenses}}{\text{income}}" display />

Do **not** redraw both pies — one multiplication chain is enough.

## 3. Line graph — cumulative vs yearly

Examiners label the Y-axis “production (in tonnes)” but the graph is **cumulative**. Students subtract the wrong years.

**Tactic:** Year **t** value = point(t) − point(t−1). Underline “cumulative” in the question stem.

## 4. Bar + table hybrid (time zones / shifts)

Bars show **totals**; a small table gives **break-up** for one category only.

**Tactic:** Answer questions that need only the table first (easy marks). Leave “total minus known parts” for last.

## 5. Caselet with successive % change

A paragraph describes **two years of % growth** on different bases.

**Tactic:** Use multipliers:

<Math math="\text{Final} = \text{Base} \times (1 + r_1/100) \times (1 + r_2/100)" display />

Never add percentages unless the bases are identical.

<Callout title="Time budget" variant="warn">
IBPS PO Prelims: ~15 DI questions in ~20 minutes → **~80 seconds per question**. If a set looks unfamiliar after 90 seconds of reading, mark and return — do not sink five minutes.
</Callout>

## Accuracy checklist

1. **Units** — lakh vs crore, % vs absolute.
2. **Average vs total** — “per month” when the table is quarterly.
3. **Approximation** — when options are far apart, round to one significant digit.
